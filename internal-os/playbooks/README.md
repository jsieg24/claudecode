## How to Use Playbooks

Playbooks are **tactical execution guides**. They include:

1. **Strategy** - Why this flow matters
2. **Structure** - Recommended email sequence
3. **Copy frameworks** - What to say in each email
4. **Subject lines** - Tested examples
5. **Timing** - When to send
6. **Optimization** - How to improve performance

---

## Playbook vs SOP

| Playbook | SOP |
|----------|-----|
| *What* to build | *How* to do a process |
| Retention tactics | Business operations |
| Client-facing work | Internal procedures |
| Flexible by client | Consistent across all |

---

## Creating New Playbooks

When documenting a new tactic:

1. Start with the strategy (why does this work?)
2. Show the structure (visual/timeline)
3. Provide copy frameworks (not just examples)
4. Include real performance data when possible
5. Add optimization ideas
