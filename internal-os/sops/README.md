## How to Use SOPs

1. **Follow them exactly** for consistency
2. **Flag gaps** when you encounter edge cases
3. **Propose updates** in weekly team meeting
4. **Train new hires** using these docs

---

## SOP Template

When creating a new SOP, use this structure:

```markdown
# [SOP Name]

## Overview
Brief description of what this SOP covers and when to use it.

## Owner
Who is responsible for this process.

## Trigger
What initiates this process.

## Steps
1. Step one
2. Step two
3. Step three

## Checklist
- [ ] Item 1
- [ ] Item 2

## Tools Needed
- Tool 1
- Tool 2

## Common Issues & Solutions
| Issue | Solution |
|-------|----------|

## Related SOPs
- Link to related SOP
```
