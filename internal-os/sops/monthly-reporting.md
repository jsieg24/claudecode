# Monthly Reporting SOP

## Overview
Standardized process for pulling, building, and delivering monthly performance reports to clients.

## Owner
**Primary:** Cathy Ang (data pulling, report building)
**Review:** Emma Hughes (insights, recommendations)

## Trigger
- First week of each month (for previous month's data)
- Some clients may have custom dates (track in client tracker)

---

## Reporting Calendar

| Timing | Action |
|--------|--------|
| 1st-3rd of month | Pull all client data from Klaviyo |
| 3rd-5th of month | Build reports, add insights |
| 5th-7th of month | Internal review (Emma reviews Cathy's reports) |
| 7th-10th of month | Deliver to clients |

---

## Step-by-Step Process

### Step 1: Pull Data from Klaviyo (Cathy)

For each client, export:

**Flow Performance**
- [ ] All active flows
- [ ] Metrics: Recipients, Open Rate, Click Rate, Revenue (if tracked)
- [ ] Date range: Previous month

**Campaign Performance**
- [ ] All campaigns sent in the month
- [ ] Metrics: Recipients, Open Rate, Click Rate, Unsubscribe Rate, Revenue
- [ ] Compare to previous month

**List Health**
- [ ] Total list size (start of month vs end)
- [ ] New subscribers
- [ ] Unsubscribes
- [ ] Engagement breakdown (engaged vs. unengaged)

**Revenue Attribution** (if Shopify connected)
- [ ] Total Klaviyo-attributed revenue
- [ ] Revenue by flow
- [ ] Revenue by campaign
- [ ] % of total store revenue

### Step 2: Build the Report (Cathy)

Use the standard report template (Google Slides or Sheets).

**Report Sections:**

1. **Executive Summary**
   - One paragraph: How did the month go?
   - Key wins
   - Key metric changes

2. **KPI Dashboard**
   - Total Klaviyo Revenue
   - Email Revenue
   - SMS Revenue (if applicable)
   - List Size / Growth
   - Average Open Rate
   - Average Click Rate

3. **Flow Performance**
   - Table of all flows with metrics
   - Highlight top performers
   - Flag any underperformers

4. **Campaign Performance**
   - Table of all campaigns
   - Best performing campaign
   - Insights on what worked

5. **List Health**
   - Growth trend chart
   - Engagement breakdown
   - Deliverability notes (if issues)

6. **What We Did This Month**
   - Bullet list of work completed
   - Link to relevant ClickUp tasks if helpful

7. **Next Month Priorities**
   - What's planned
   - Any requests/decisions needed from client

### Step 3: Add Insights (Emma)

Emma reviews each report and adds:
- [ ] Strategic context (why metrics moved)
- [ ] Recommendations for improvement
- [ ] Opportunities to highlight
- [ ] Any concerns to address proactively

### Step 4: Internal QA

Before sending, check:
- [ ] Client name is correct (no copy-paste errors!)
- [ ] Date range is correct
- [ ] Numbers match Klaviyo
- [ ] No typos or formatting issues
- [ ] Recommendations are specific and actionable

### Step 5: Deliver to Client

**Delivery Options (by client preference):**
- Email with report attached/linked
- Slack message with report linked
- Live call walkthrough (for key accounts)

**Email Template:**
```
Subject: [Client Name] - [Month] Retention Report

Hi [Name],

Here's your monthly retention performance report for [Month].

[Link to Report]

Quick highlights:
- [Win 1]
- [Win 2]
- [Key metric]

Let me know if you have any questions or want to schedule a call to discuss.

Best,
[Your name]
```

### Step 6: Log Completion

- [ ] Update client tracker: "Last Report" = [Date]
- [ ] Save report to Google Drive > Clients > [Name] > Reports
- [ ] Note any client feedback in tracker

## Metrics Benchmarks

Use these as reference points in reports:

| Metric | Good | Great | Needs Work |
|--------|------|-------|------------|
| Open Rate | 35-45% | 45%+ | <30% |
| Click Rate | 1-2% | 2%+ | <1% |
| Unsubscribe Rate | <0.3% | <0.2% | >0.5% |
| Klaviyo Revenue % | 25-30% | 30%+ | <20% |
| List Growth | 3-5%/mo | 5%+ | Flat/Declining |

*Note: Benchmarks vary by industry. Use these as general guidance.*

---

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Revenue tracking not set up | Note in report, recommend setup |
| Client hasn't looked at reports | Offer live walkthrough call |
| Metrics declined | Lead with context, explain why, show plan |
| Missing data/access issues | Flag immediately, don't wait until report is due |
| Client wants different metrics | Customize template, document in tracker |

## Time Investment Per Client

| Task | Time |
|------|------|
| Data pull | 15 min |
| Report building | 30 min |
| Insights/review | 15 min |
| QA and delivery | 10 min |
| **Total** | **~70 min** |

For 15 clients: ~17-18 hours of reporting work per month
