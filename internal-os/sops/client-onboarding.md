# Client Onboarding SOP

## Overview
This SOP covers the end-to-end process for bringing a new client live, from signed contract to first campaign launch.

## Owner
**Primary:** Emma Hughes
**Support:** Cathy Ang

## Trigger
- Signed contract received
- Joe confirms handoff to team

## Timeline
**Target:** Client fully onboarded within 2 weeks of contract signing

---

## Phase 1: Internal Setup (Day 1-2)

### Joe's Handoff
- [ ] Share signed contract in Google Drive > Clients > [Client Name]
- [ ] Post in #internal Slack: "New client: [Name] - [Brief context]"
- [ ] Assign primary owner (Emma or split with Cathy)
- [ ] Schedule internal kickoff (15 min)

### Internal Kickoff Agenda
1. Client background & goals
2. Contract scope (what's included)
3. Known challenges or opportunities
4. Key contacts on client side
5. Assign onboarding tasks

### ClickUp Setup
- [ ] Create client project from template
- [ ] Add client to appropriate ClickUp space
- [ ] Create onboarding task list
- [ ] Set due dates for all onboarding milestones

### Google Drive Setup
- [ ] Create folder: `Clients > [Client Name]`
- [ ] Subfolders: `Strategy`, `Reports`, `Assets`, `Creative`
- [ ] Copy Monthly Report template to Reports folder

---

## Phase 2: Client Kickoff (Day 2-5)

### Pre-Kickoff Prep
- [ ] Review client's current Klaviyo account (if access granted)
- [ ] Audit existing flows and campaigns
- [ ] Review Shopify store (products, pricing, brand voice)
- [ ] Prepare kickoff deck with initial observations

### Schedule Kickoff Call
- [ ] Send calendar invite (60 min)
- [ ] Include agenda in invite
- [ ] Request attendees: primary contact + anyone else relevant

### Kickoff Call Agenda (60 min)
1. **Introductions** (5 min) - Team intro, roles
2. **Their Goals** (15 min) - What does success look like?
3. **Current State** (10 min) - What's working, what's not
4. **Our Approach** (15 min) - Retention roadmap overview
5. **Access & Logistics** (10 min) - See access checklist below
6. **Next Steps** (5 min) - Timeline and immediate actions

### Access Checklist (request during/after kickoff)
- [ ] Klaviyo account access (Admin level preferred)
- [ ] Shopify store access (Staff account with analytics)
- [ ] Slack Connect channel (or create one)
- [ ] Brand assets (logo, fonts, colors, photo library)
- [ ] Any existing style guide or brand guidelines

---

## Phase 3: Audit & Strategy (Day 5-10)

### Klaviyo Audit
- [ ] Document all existing flows (status, performance)
- [ ] Review list health (size, growth, engagement)
- [ ] Check segment structure
- [ ] Evaluate email template design
- [ ] Review deliverability (open rates, spam complaints)

### Retention Strategy Development
- [ ] Identify quick wins (low effort, high impact)
- [ ] Build 90-day roadmap
- [ ] Prioritize flow builds/optimizations
- [ ] Define campaign calendar approach
- [ ] Set KPI targets

### Strategy Presentation
- [ ] Schedule strategy call (45 min)
- [ ] Present audit findings
- [ ] Share 90-day roadmap
- [ ] Get client approval on priorities
- [ ] Align on communication cadence

---

## Phase 4: Execution Begins (Day 10-14)

### First Deliverables
- [ ] Build/optimize highest priority flow
- [ ] Set up reporting dashboard or template
- [ ] Schedule first campaign (if applicable)
- [ ] Complete any quick wins identified

### Communication Rhythm Established
- [ ] Slack channel active
- [ ] First weekly update sent
- [ ] Monthly report date scheduled
- [ ] Recurring check-in on calendar (if needed)

### Client Tracker Updated
- [ ] Add client to master tracker spreadsheet
- [ ] All fields populated
- [ ] Status set to "Active"

---

## Onboarding Checklist Summary

```
□ Internal kickoff completed
□ ClickUp project created
□ Google Drive folder set up
□ Client kickoff call completed
□ All access granted (Klaviyo, Shopify, Slack)
□ Audit completed
□ 90-day strategy presented and approved
□ First deliverable completed
□ Communication rhythm established
□ Added to client tracker
```

---

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Client slow to grant access | Follow up Day 3, escalate to Joe if no response by Day 5 |
| Klaviyo account is a mess | Extend audit phase, document technical debt |
| Client has unrealistic expectations | Joe joins call to reset expectations |
| No brand assets available | Use store as reference, create simple templates |
| Client wants to change scope immediately | Document request, Joe reviews contract implications |
