# Monthly Report Template

## Purpose

The monthly report communicates client performance and our value. It should be:
- Easy to understand (even for non-marketing people)
- Visually clear
- Focused on results
- Forward-looking (not just backward-looking)

**Format:** Google Slides (recommended) or PDF
**Location:** `Google Drive > Boring Ecom > Templates > Monthly Report Template - MASTER`

---

## Report Structure

### Slide 1: Cover

```
[Client Logo]

Monthly Retention Report
[Month Year]

Prepared by Boring Ecom
```

## Design Guidelines

### Colors
- Use client's brand colors where possible
- Or use neutral Boring Ecom palette
- Green for positive metrics, red for negative

### Fonts
- Clean, readable fonts
- Consistent sizing
- Don't overcrowd slides

### Charts
- Simple bar/line charts
- Label everything
- Use client-appropriate style

### Length
- Target: 8-10 slides
- Appendix can add more if needed
- Quality over quantity

---

## Pulling the Data

### From Klaviyo

**Flows:**
Analytics > Flows > Select date range > Export

**Campaigns:**
Campaigns > All Campaigns > Filter by date > Export or screenshot

**List:**
Audience > Lists > Click into main list > Growth analytics

**Revenue:**
Analytics > Dashboard > Klaviyo-attributed revenue

### Data Formatting

- Round percentages to whole numbers or one decimal
- Format revenue with $ and commas ($45,000)
- Use consistent date formats

---

## Delivery Options

### Option A: Email with Link
Send Google Slides link (view only) with summary email.

### Option B: PDF Attachment
Export to PDF, attach to email.

### Option C: Live Walkthrough
Schedule 30-min call, present report, discuss.

**Recommended for:**
- New clients (first 3 months)
- Underperforming months
- Strategic accounts

---

## Report Customization by Client

Some clients may want different things:

| Client Preference | Adjustment |
|-------------------|------------|
| "Keep it short" | Executive summary only + KPIs |
| "I want all the data" | More appendix, detailed tables |
| "Focus on revenue" | Lead with revenue, minimize other metrics |
| SMS subscriber | Add SMS performance section |
| Shopify integration | Add % of total store revenue |

Document preferences in Client Tracker.
